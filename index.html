The bug is: [describe it]." --- ## What This App Is Single-file HTML app for Indian motor insurance surveyors. No backend, no server, no database. Runs entirely in the browser. State lives in `localStorage`. AI extraction uses Groq API (Llama 4 Scout vision model). Voice input uses browser-native Web Speech API (no API key needed). PDF documents are converted page-by-page to images via PDF.js before being sent to Groq. Google Drive sync uses the index-file approach — no API Key needed, only OAuth Client ID. **Filename:** `SurveyOS_v7_fixed.html` (~3090 lines) **External CDN dependencies:** - Google Fonts (Barlow family) - PDF.js 3.11.174 (`pdf.min.js` + `pdf.worker.min.js` from cdnjs) - Google Identity Services (`accounts.google.com/gsi/client`) — Drive OAuth --- ## Claim Object Shape (stored in localStorage) ```json { "id": "claim_1708600000000", "surveyType": "spot", "vehicleType": "private", "depType": "nil", "status": "docs-pending", "updatedAt": "2026-02-22T10:00:00.000Z", "regNo": "MH15AV1234", "insuredName": "Ramesh Kumar", "claimNo": "SPOT-MH15AV1234", "insurer": "HDFC ERGO General Insurance Co. Persist in claim.status. - manualStatus global holds the override for the open claim. - loadClaim() restores manualStatus if stored status was completed or on-hold. - setClaimStatus(null) reactivates — reverts to computeStatus(). - getCurrentClaimData() uses `manualStatus || computeStatus()` — CRITICAL: auto-save calls this every 3 seconds, so manualStatus must be set before saving or the override is lost. - manualStatus is reset to null in createClaim() — new claims always start with computed status. --- ## Assessment Row Shape ```json { "particulars": "Front Bumper Assembly", "estimated": 5000, "assessed": 4500, "partType": "plastic", "gst": 28, "section": "parts", "allowed": true } ``` section: "parts" | "labour" | "paint" partType: "metal" | "plastic" | "glass" | "labour" | "paint" allowed: false = disallowed — struck through, excluded from totals **gst: per-row GST% is now functional** — recalcSummary() uses r.gst per row for both parts and labour/paint. Do not hardcode 18% anywhere in the assessment engine. --- ## Spot Damage Row Shape ```json { "id": 1708600000000.123, "component": "BODY PANELS", "damage": "Front bumper dented and cracked", "estimatedCost": 4500 } ``` estimatedCost always initialised to 0 in addSpotDamageRow(). Old rows without it are handled with row.estimatedCost||0 everywhere. --- ## ALL_FIELD_IDS Every input/select/textarea that persists. Page refresh clears files. 2. psPhotos is session-only. Intentional — surveyor re-uploads each session. 3. Old claims without surveyType default to 'final' on load. 4. Spot claim number auto-fills SPOT-REGNO. Wizard pre-fills live via onWzRegNoInput. createClaim() catches it if still blank. computeStatus() bypasses claim number check for spot surveys. Format: MH-15-AV-1234 → SPOT-MH15AV1234 (hyphens stripped). 5. PDF.js needs CDN. Offline = PDF pages won't render. 6. Drive OAuth needs http:// origin. Will not work on file:// protocol. 7. Web Speech API needs http:// in Chrome. Not supported in Safari or Firefox. 8. gDriveFolderId stored in two places — localStorage claim object AND surveyos_index.json on Drive. reconcileDriveClaims() restores all links on reconnect. 9. driveUploadFile checks for existing file by name before uploading — avoids duplicates. 10. Adding new input fields — must add id to ALL_FIELD_IDS or field won't persist. Checkboxes are handled automatically via el.type==='checkbox'. 11. Auto-save — 3-second debounce on form change event while claim is open. Uses getCurrentClaimData() which calls manualStatus||computeStatus() — so manualStatus must be set in the global before the debounce fires. 12. manualStatus is reset to null in createClaim(). Always reset it there if you add new claim creation paths. 13. estimatedCost on spotDamageRows — always initialised to 0 in addSpotDamageRow(). Old claims guard with row.estimatedCost||0. 14. extractEstimateMulti vs extractDoc — only routes to extractEstimateMulti when key is 'estimate' AND uploadedDocs.estimate is array with length > 1. Single-file estimates including multi-page PDFs go through extractDoc as before. 15. Signature size — getSigBlock() uses 96px/110px. Profile previews 180px. Do not reduce without checking all report builders. Photo sheets deliberately have NO signature/stamp. 16. Photo Sheet empty slots print white — never add grey background or placeholder icon. 17. Photo Sheet multi-page — page-break-before:always on each sheet from sheet 2. Each sheet has own header + footer. No signature in photo sheet footer. 18. Photo Sheet photos are never cropped — object-fit:contain. Do NOT change to object-fit:cover. 19. psLandscape is session-only (not persisted). Resets to false on page reload. 20. Fee bill GST row — controlled by fee-include-gst checkbox. Old claims without this field default to unchecked (no GST). Surveyor must explicitly opt in. 21. Spot report ENCL line — if spot-encl is empty, prints a long blank underline for manual fill. If filled, prints the text. Always present at the bottom of the spot report. 22. Spot report Repairs line — always prints in the report, even if blank. 23. Per-row GST% in assessment table is live — recalcSummary() uses r.gst per row. Do not revert to hardcoded 9%/18%. 24. Policy excess of ₹0 is valid — recalcSummary() treats a blank excess field as 500 but an explicit 0 as 0. Do not use the ||500 fallback pattern. 25. Groq API key is NOT in ALL_FIELD_IDS and is NOT in claim.fields — it is stored only under 'groq_api_key' in localStorage. Do not add sp-groq-key back to ALL_FIELD_IDS. 26. checkDL() (was checkSpotDL in v7) — now reads f-dl-* fields. If you see references to checkSpotDL() or spot-mdl-verified in any code, they are from before the v8 merge and must be updated. 27. Suggestion chips in buildCauseSuggestions() and buildAssessSuggestions() use data-* attributes and addEventListener — they do NOT use inline onclick with raw text. Do not revert to inline onclick as it breaks on special characters. --- ## How to Debug in a New Chat ```javascript JSON.parse(localStorage.getItem('os_claims')) // all claims loadClaims().length // claim count console.log(surveyType, vehicleType, currentClaimId) console.log(manualStatus, computeStatus()) console.log(gDriveFolderId, gDriveToken ?
